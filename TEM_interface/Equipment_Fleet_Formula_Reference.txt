1. SHEET OVERVIEW & DATA FLOW DIAGRAM
================================================================================

Data flows in this order:

  Equipment Master Data  ──►  Equipment (VLOOKUP bridge)
         │                         │
         │                         ▼
         │                    Productivity ◄── Assumptions_Dashboard
         │                         │                    │
         │                         ▼                    │
         │                      Fleet  ◄────────────────┘
         │                         │
         │                         ▼
         │              Production Schedule (Hard Inputs)
         │                         │
         └─────────────────────────┘

KEY RELATIONSHIPS:
- Equipment Master Data: FIXED INPUT database of all equipment specs (Make, Model, Cost, Engine HP, Capacity, Availability, Utilization, Life, Spares%, Fuel, Power, Tyres)
- Equipment Sheet: Acts as a LOOKUP BRIDGE - uses VLOOKUP to pull data from Equipment Master Data for the specific equipment selected in Fleet
- Fleet Sheet: Selects which equipment to use (dropdown) and references Equipment via VLOOKUP; also reads Production Schedule volumes and Productivity outputs to calculate fleet counts
- Productivity Sheet: Calculates annual production capacity per machine using equipment specs (from Equipment) and assumption parameters (from Assumptions_Dashboard)
- Assumptions_Dashboard: Contains SRK standard assumptions (density, swell factor, working days, etc.)
- Production Schedule: Contains year-by-year hard inputs (coal/ore, waste, haul distances, bench heights)

8. FLEET SHEET (Fleet Sizing Calculations)
================================================================================

The Fleet sheet calculates the required number of each equipment type per year.
It reads volumes from Production Schedule, capacities from Productivity, and
equipment specs from Equipment (which in turn pulls from Equipment Master Data).

8.1 MATERIAL VOLUME CONVERSION
──────────────────────────────
  Coal/Ore bcm:
    Fleet!G5 = 'Production Schedule'!E6 / Assumptions_Dashboard!$D$32
    → Coal Mt from D&B / Coal Density (1.72 t/cum) = Coal volume in Mbcm

  Waste IB Thin Parting (30% of total IB):
    Fleet!G6 = 'Production Schedule'!E11 × Fleet!$F$6
    → Total Waste × 0.3 (Thin Parting fraction) — F6 = 0.3

  Waste IB Thick Parting (remainder):
    Fleet!G7 = 'Production Schedule'!E11 - Fleet!G6
    → Total Waste - Thin Parting = 70% of total waste

  Waste OB:
    Fleet!G8 = 'Production Schedule'!E10
    → Overburden volume directly from Production Schedule

  Waste Thick Parting (OB + IB Thick):
    Fleet!G9 = G7 + G8 (sum of IB thick and OB)


8.2 DRILL FLEET SIZING
───────────────────────
  Coal/Ore Drill (115mm):
    Required = CoalVolume(bcm) / Productivity!$E$26 × 10^6
    Fleet!G12 = G5 / Productivity!$E$26 × 10^6
    Actual = ROUNDUP(Required, 0)
    Fleet!G13 = ROUNDUP(G12, 0)

  Waste IB Thin Parting Drill (160mm):
    Required = ThinPartingVolume / Productivity!$F$26 × 10^6
    Fleet!G16 = G6 / Productivity!$F$26 × 10^6
    Actual = ROUNDUP(Required, 0)

  Waste Thick Parting Drill (250mm):
    Required = ThickPartingVolume / Productivity!$D$26 × 10^6
    Fleet!G20 = G9 / Productivity!$D$26 × 10^6
    Actual = ROUNDUP(Required, 0)


8.3 SHOVEL/EXCAVATOR FLEET SIZING
──────────────────────────────────
  Top Soil (1.0 cum shovel):
    Required = TopSoilVolume / Productivity!$F$49 × 10^6
    Fleet!G26 = G25 × 10^6 / Productivity!$F$49

  Thin Parting + Coal (4.6 cum shovel):
    Material = Coal(bcm) + ThinParting + TopSoil
    Fleet!G30 = G5 + G6 + G25
    Required = G30 × 10^6 / Productivity!$G$49
    Fleet!G31 = G30 × 10^6 / Productivity!$G$49
    Actual = ROUNDUP(Required, 0)

  Waste OB + Thick Parting (10 cum shovel):
    Material = IB_Thick + OB
    Fleet!G34 = G7 + G8
    Required = G34 × 10^6 / Productivity!$E$49
    Actual = ROUND(Required, 0)

  Miscellaneous 01 (3.4 cum shovel):
    Material from 'Production Schedule' rehandling (conditional)
    Fleet!G39 = IF($A$38="Yes", 'Production Schedule'!E13, 0)
    Required = G39 × 10^6 / Productivity!$H$49


8.4 SURFACE MINER FLEET SIZING
───────────────────────────────
  SM Coal/Ore:
    Required = 'Production Schedule'!{col}7 × 10^6 / Productivity!$D$35
    Fleet!G50 = 'Production Schedule'!E7 × 10^6 / Productivity!$D$35
    Actual = ROUNDUP(Required, 0)


8.5 FRONT-END LOADER FLEET SIZING
──────────────────────────────────
  FEL for SM Coal (6.4 cum):
    Material = 'Production Schedule'!{col}7 / Assumptions_Dashboard!$D$32
    Fleet!G55 = 'Production Schedule'!E7 / Assumptions_Dashboard!$D$32
    Required = G55 / Productivity!$K$49 × 10^6
    Actual = ROUNDUP(Required, 0)

  FEL Miscellaneous (1.7 cum):
    Material = 'Production Schedule'!{col}12 / Assumptions_Dashboard!$D$32
    Fleet!G60 = 'Production Schedule'!I12 / Assumptions_Dashboard!$D$32
    Required = G60 × 10^6 / Productivity!$L$49
    Actual = ROUNDUP(Required, 0)


8.6 DUMPER/TRUCK FLEET SIZING
─────────────────────────────
  Topsoil (20t Tipper):
    Volume = G25 (same as top soil from section 8.3)
    Required = IFERROR(Volume × 10^6 / Productivity!{col}88, 0)
    Fleet!G67 = IFERROR(G66 × 10^6 / Productivity!D88, 0)
    Actual = ROUNDUP(Required × (1 + StandbyReserve%), 0)
    Fleet!G68 = ROUNDUP(G67 × (1 + Assumptions_Dashboard!$D$113), 0)

  Thin Parting + Rehandling (35t Tipper):
    Volume = IF(RehandlingIncluded, ThinParting + Rehandling, ThinParting)
    Fleet!G71 = IF($A$70="Yes", G6 + 'Production Schedule'!E13, G6)
    Required = IFERROR(Volume × 10^6 / Productivity!{col}82, 0)
    Actual = ROUNDUP(Required × (1 + StandbyReserve%), 0)

  Waste OB + Thick Parting (100t Dumper):
    Volume = IB_Thick + OB = G7 + G8
    Required = IFERROR(Volume × 10^6 / Productivity!{col}94, 0)
    Actual = ROUNDUP(Required × (1 + StandbyReserve%), 0)

  Coal/Ore (40t Dumper):
    Volume = 'Production Schedule'!{col}5 / Assumptions_Dashboard!$D$32
    Fleet!G81 = 'Production Schedule'!E5 / Assumptions_Dashboard!$D$32
    Required = IFERROR(Volume × 10^6 / Productivity!{col}70, 0)
    Fleet!G82 = IFERROR(G81 × 10^6 / Productivity!D70, 0)
    Actual = ROUNDUP(Required × (1 + StandbyReserve%), 0)
    Fleet!G83 = ROUNDUP(G82 × (1 + Assumptions_Dashboard!$D$113), 0)


8.7 DOZER, GRADER, CRANE FLEET SIZING
──────────────────────────────────────
  These use a RATIO-BASED formula proportional to coal production:

  Formula Pattern:
    Fleet per year = ROUNDUP(YearCoalProduction / MaxCoalProduction × PeakFleetCount, 0)

  Example - Track Dozer/ 405 HP (Row 87, Peak=6):
    Fleet!G87 = ROUNDUP('Production Schedule'!E$5 / MAX('Production Schedule'!$E$5:$AA$5) × Fleet!$E87, 0)
    Where Fleet!$E87 = 6 (peak fleet count)

  This same pattern applies to:
    Row 87: Track Dozer/ 405 HP         (Peak: 6)
    Row 88: Wheel Dozer                 (Peak: 0, not used)
    Row 89: No. of Dozer Required       (Peak: 2)
    Row 90: Ripper Dozer/ 450TPH        (Peak: 0, not used)
    Row 91: No. of Dozer Required       (Peak: 2)
    Row 92: Track Dozer/ 192 HP         (Peak: 0, not used)
    Row 93: No. of Dozer Required       (Peak: 2)
    Row 95-98: Graders (same ratio pattern)
    Row 100+: Cranes and Auxiliary (same ratio pattern)
